# indexportal-leyu-lab

## 项目简介

这是一个用于归档与展示多个独立 HTML 页面的仓库。  
仓库本身不指向特定域名或具体网站，仅作为静态页面集合的存储与发布空间。  
每个页面可独立访问，用于信息展示、功能演示或内容存档。

## 目录说明

```
.
├── index.html          # 仓库入口页面（可选）
├── pages/              # 存放各独立 HTML 页面
│   ├── page1.html
│   ├── page2.html
│   └── ...
├── assets/             # 页面共享资源（样式、脚本、图片等）
│   ├── css/
│   ├── js/
│   └── images/
└── README.md           # 本文件
```

- `pages/` 目录用于存放所有归档的 HTML 页面文件，可按功能或类型组织子目录。
- `assets/` 目录存放页面引用的公共资源，便于统一管理与更新。
- 根目录下的 `index.html` 为可选入口，可用于展示页面列表或导航。

## 页面归档说明

本仓库中的 HTML 页面均作为独立归档存在，内容涵盖但不限于：

- 信息展示页面
- 工具或功能演示
- 静态内容存档

每个页面均保持独立完整，不依赖外部不可控资源（除非明确标注）。  
页面之间无强制关联，可单独部署或访问。

## 维护说明

- 新增页面：在 `pages/` 目录下创建新的 HTML 文件，并更新相关资源引用。
- 页面更新：直接修改对应文件，保持版本历史可追溯。
- 资源管理：公共资源统一存放于 `assets/`，避免重复。
- 清理归档：若页面不再需要，建议保留记录或移入 `archive/` 目录。

## 使用方式

1. 克隆本仓库到本地。
2. 在 `pages/` 目录中添加或编辑 HTML 文件。
3. 可通过 GitHub Pages 或其他静态托管服务直接部署。

> 本仓库仅用于页面归档与展示，不涉及任何商业推广或特定服务。
